幻想兽物语 · 功能清单与技术实现思维导图
多人在线 RPG · Unity 2022.3 URP · Photon PUN2 · xLua · Addressables
幻想兽物语
项目总览
多角色系统
角色选择与切换
用 ScriptableObject 配置每个角色的名称、图标、Prefab 名和能力介绍，统一由一个角色信息库管理。选择面板读取库展示，选角色后通过 Photon 同步切换。
SO 配置 + Photon RPC
角色属性系统
每个角色的血量、攻击力、防御力、暴击率、攻击速度、移动速度等全部由 SO 配置，运行时由属性基类管理增减。卡牌和符文效果最终都作用在属性上。
SO 数据驱动
角色行为 Lua 热更
每个角色的元素切换、对象池注册、死亡处理等逻辑用 Lua 实现，C# 通过桥接器调用。Lua 出错时自动降级到 C# 默认行为，不崩游戏。
xLua 桥接 + 自动降级
战斗系统
攻击系统
攻击逻辑优先走 Lua，Lua 没实现则走 C# 默认。支持连射机制（一次攻击发射多枚投射物）和攻击间隔冷却。攻击时生成投射物并同步到其他客户端。
Lua 优先 + C# 降级 + RPC 同步
元素切换
不同角色拥有不同元素组合（如冰/火/雷/草），切换元素时动态注册对应特效的对象池，并通过 RPC 通知其他客户端初始化。
元素枚举 + 动态对象池 + RPC
投射物与特效
包含火球、射线、冲击炮（4 种元素变体）、鬼灵（4 种元素变体）等投射物，通过工厂模式创建，对象池复用，Addressables 加载预制体。
工厂模式 + 对象池 + Addressables
伤害计算
伤害数据（值、目标、元素、暴击）通过事件通道广播，敌人订阅事件处理扣血。暴击和元素克制影响最终伤害值。
EventChannel 事件广播
卡牌升级
升级时弹出 3 张随机卡牌（普通/史诗/传说），选卡后通过效果接口应用属性加成。每 3 级额外触发一次专属卡牌选择。卡牌数据和效果全部由 SO 配置。
SO 卡牌库 + 效果接口 + UI 动画
敌人系统
状态机 AI
敌人有 Idle、Run、Attack、Die 四种状态，通过状态机管理切换。追踪最近的玩家，进入攻击范围后攻击。仅房主执行 AI 逻辑，其他客户端通过 Photon 同步位置和动画。
状态机 + MasterClient 权限
数据驱动配置
敌人的血量、攻击力、移速、攻击间隔、经验掉落、道具掉落概率全部由 SO 配置，策划在 Inspector 调数值就能改平衡。波次生成配置（间隔、上限、预制体）也走 SO。
SO 数据驱动
难度缩放
根据游戏时间动态计算怪物数量倍率、生成间隔和精英怪出现概率，游戏越久越难。
时间驱动的公式缩放
对象池回收
敌人死亡后不销毁，3 秒后通过事件通道回收到对象池。回收时重置动画、物理、属性、状态机等全部状态，下次生成时直接复用。
对象池 + 状态重置
Boss 系统
Boss 有独立配置和生成器，死亡后触发事件链：通知 GameManager → 等 10 秒 → 存档 → RPC 切换场景回大厅。
事件链 + 场景切换
符文与背包
符文数据
每枚符文的数值（攻击力%、暴击率%、防御%等）和特殊技能由 SO 定义，通过 Addressables 加载。支持角色专属限制（某些符文只有特定角色能用）。
SO 配置 + Addressables
效果映射（可热更）
符文效果的"标签→C#方法名"映射表用 Lua 编写，C# 通过反射调用对应属性方法。热更新时在 Lua 里加一行就能新增效果类型，不改 C#。Lua 不可用时走 C# 回退。
Lua 映射表 + C# 反射 + 回退
装备与快照
大厅选 2 个符文槽位，出发前捕获装备 ID 存到静态快照，场景切换后应用器读取快照，将符文效果应用到玩家属性。跨场景不丢失。
静态快照 + 跨场景传递
符文背包
用内存列表存储已收集的符文 ID，支持去重和查询。数据由存档系统统一持久化，读档时恢复。
内存列表 + 存档持久化
商店系统
购买流程
检查库存→检查是否已拥有→扣金币→加入符文背包→发事件通知 UI 刷新。支持限量/不限量、允许/禁止重复购买等配置。
SO 商店配置 + 事件通知
金币系统
对局结算时按公式计算金币（击杀数×50 + 伤害×0.1），通过事件通道通知 UI 更新显示。金币余额由存档系统持久化。
公式计算 + 事件通知 + 存档
库存与购买记录
每个符文的购买次数记录在字典中，计算剩余库存。购买记录随存档持久化，跨对局保持。
字典记录 + 存档持久化
局内任务
任务类型
支持击杀任务（区域内击杀 N 只怪）和护送任务（护送 N 个机器人到目标区域）。每种任务有时限，超时判定失败。
任务基类 + 子类扩展
任务调度与同步
任务激活后通过 RPC 同步到所有客户端，通过 Addressables 实例化任务区域 Prefab，房主倒计时，进度通过 RPC 实时同步。
RPC 同步 + Addressables 实例化
击杀上报
敌人死亡时发事件携带位置和类型，任务管理器检查是否在任务区域内，在区域内则计数，计数达标判定完成。
事件上报 + 区域判定
任务奖励
完成后触发卡牌选择（必定 3 张专属强化卡），发放经验奖励，销毁任务区域。失败则清除区域并通知 UI。
事件链 + 卡牌系统联动
局外任务
任务配置
用 SO 定义任务（击杀 N 只怪、造成 N 伤害、收集 N 金币等），任务数据库通过 Addressables 加载，可热更。
SO 任务库 + Addressables
进度管理
局内打怪/造成伤害等事件实时累加到暂存区，打开任务面板时一次性合并到累计进度，存档，返回增量驱动 UI 动画。
暂存 + 合并 + 动画驱动
跨对局累积
累计进度序列化到存档文件，每次对局新增的进度叠加到历史值，跨对局持续累积。支持版本兼容和数据校验。
存档持久化 + 版本兼容
存档系统
数据收集与分发
存档时从金币、符文装备、符文背包、任务进度、商店购买记录、对局统计等各系统收集数据，序列化为 JSON。读档时反序列化后分发给各系统恢复。
统一收集 + JSON 序列化
文件读写
存档文件保存在 persistentDataPath，提供存在检查、保存、读取、删除接口。退出游戏时自动保存。
文件 IO + 自动保存
加密与版本兼容
JSON 序列化后可选加密写入，防止篡改。旧版本存档按版本号逐步升级补全字段，校验非法 ID。
加密 + 版本迁移 + 数据校验
网络系统
接口隔离
定义了 8 个网络服务接口，所有代码通过服务定位器访问，不直接依赖 Photon。替换网络方案只需改实现类，不动业务代码。
接口隔离 + 服务定位器
RPC 分层
RPC 方法按架构分层管理：应用层管场景切换和经验同步，领域层管敌人销毁和元素池，表现层管 UI 动画。各层 RPC 互不混杂。
三层 RPC Bridge
经验球非网络化
经验球不走 PhotonNetwork.Instantiate，而是房主生成 ID 后 RPC 通知各客户端从本地对象池生成。拾取时 RPC 认领并隐藏，减少网络带宽和实例化开销。
ID 同步 + 本地对象池
网络对象池
敌人、投射物、特效、道具等预制体预注册到网络对象池，房主创建时通知各客户端从本地池取出，回收时还回池。减少 Photon 实例化开销。
预注册 + 本地池 + RPC 协调
UI 系统
自研 UI 框架
Unity 没有内置 UI 管理框架，自研了一套：界面基类（打开/关闭/动画/ESC）、单例管理器（注册/导航/遮罩）、导航栈（A→B→关B→回A）、分层渲染（背景/普通/弹窗/覆盖）。
基类 + 管理器 + 导航栈 + 分层
数据更新方式
UI 不直接调用业务代码，而是订阅事件通道。血条订阅 HP 变化事件、金币显示订阅金币事件，收到事件后更新显示。业务和 UI 彻底解耦。
EventChannel 订阅
HUD 与小地图
战斗 HUD 包含 Boss 血条、伤害数字、属性面板、队伍信息、时间进度。小地图用独立俯视相机渲染到 RenderTexture，标记玩家和敌人位置。
事件订阅 + RenderTexture
热更新
资源热更
游戏启动时对比内置 catalog 和远程 catalog 的 hash，不同则下载新 catalog 重新初始化，然后按标签批量下载变更的资源包。438 个资产支持热更，有进度 UI。
Addressables + MD5 对比
逻辑热更
角色行为、攻击逻辑、符文效果映射等用 Lua 编写，Lua 脚本本身也走 Addressables 加载，更新 Lua 等于更新游戏逻辑。C# 桥接器调用，报错自动降级。
xLua + Addressables 联动 + 降级
安全校验
加载前校验 Lua 文件 MD5 完整性，预留 RSA 签名验证，防止热更脚本被篡改。
MD5 + RSA 预留
核心基础设施
服务定位器
两个全局字典按类型存取服务实例，替代到处拖引用和 FindObjectOfType 的混乱方式。游戏启动时自动注册，任何代码按类型获取。
ServiceLocator 模式
事件系统
62 个事件通道 SO 分 4 组（战斗/玩家/游戏/UI），发布者发事件，订阅者监听，互不引用。事件通道在 Inspector 拖拽配置，生命周期独立于场景。
ScriptableObject 观察者模式
对象池
预注册预制体和数量，取出/归还复用 GameObject，减少 GC 和实例化开销。Lua 也可通过桥接方法调用。
对象池模式
