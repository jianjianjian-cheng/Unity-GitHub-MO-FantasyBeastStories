BASE LAYER — 屏幕与组件抽象
⬢ UIScreen abstract · MonoBehaviour
screenId唯一标识，用于注册查找
defaultLayerUILayer — 默认层级
useMaskbool — 是否显示遮罩
closeOnEscbool — ESC 关闭
destroyOnClosebool — 关闭时销毁
openAnimationUIAnimationBase — 打开动画 SO
closeAnimationUIAnimationBase — 关闭动画 SO
Open() → StopCoroutine(close) → SetActive(true)
  ├─ Widget.OnScreenOpened()
  ├─ OnBeforeOpen() ← 子类重写：初始化数据
  ├─ yield return openAnimation.PlayCoroutine()
  ├─ IsOpen = true · IsAnimating = false
  └─ OnAfterOpen() ← 子类重写：注册事件
Close() → StopCoroutine(open) → StartCoroutine()
  ├─ OnBeforeClose() ← 子类重写：保存状态
  ├─ yield return closeAnimation.PlayCoroutine()
  ├─ IsOpen = false · IsAnimating = false
  ├─ OnAfterClose() ← 子类重写：清理
  ├─ Widget.OnScreenClosed()
  └─ SetActive(false) / [Destroy]
⬢ UIWidget abstract · MonoBehaviour
autoBindbool — Awake 自动绑定组件
selectAnimationUIAnimationBase — 选中动画 SO
deselectAnimationUIAnimationBase — 取消选中动画 SO
hoverEnterAnimationUIAnimationBase — 悬浮进入动画 SO
hoverExitAnimationUIAnimationBase — 悬浮离开动画 SO
IsSelectedbool — 选中状态下跳过悬浮动画
PlaySelect() → IsSelected=true
  └─ StopCoroutine(deselect) → StartCoroutine(select)
PlayHoverEnter() → if IsSelected return
  └─ StopCoroutine(hoverExit) → StartCoroutine(hoverEnter)
Screen 感知: OnScreenOpened() · OnScreenClosed()
协程互斥: 每个动画独立 Coroutine 引用，播放前 StopCoroutine 对立动画
